# Изменения

## 2026-10-05 — Ручное управление сервисом

- Отключён автозапуск контейнера: Docker CLI и Compose используют restart policy `no`.
- Добавлены `scripts/start.sh`, `scripts/stop.sh`, `scripts/status.sh` для управления после входа на сервер.
- Start/stop используют существующий контейнер без пересборки; команды повторяемы и сохраняют volumes.
- Старые установки переводятся в ручной режим при start/stop/deploy; rollback сохраняет отключённый автозапуск.
- Обновлены инструкции и проверки скриптов. На текущем сервере политика изменена без пересоздания контейнера.

## 2026-10-05 — Поставка для Git и другого сервера

- Добавлены техническая документация и шаблон `.env.example` без секретов.
- Добавлены Docker installer, deploy/update с healthcheck и rollback, backup/restore, импорт авторизации и экспорт исходников/образа.
- Порт, bind address, имена и лимиты задаются через `.env`; прежний `run.sh` сохранён как обёртка.
- Добавлен `requirements.lock` по проверенному работающему образу.
- Добавлены unit tests скриптов и отдельная проверка переноса на временных volumes.
- Работающий контейнер при подготовке поставки не пересобирался и не перезапускался.

## 2026-10-02 — Первый запуск

- Русский web-интерфейс с xterm.js, интерактивным Codex CLI и Bash.
- Авторизация по паролю, Origin checks, cookie, две одновременные сессии.
- Docker deployment на порту 8080 с автозапуском, named volumes и ограничениями ресурсов.
- Потоковое извлечение npm archives для небольшого VDS.
